# Python Sales Analytics Project

## Project Overview
This project focuses on analyzing sales data using Python libraries. It performs data analysis, data cleaning, business insights, and data visualization.

## Technologies Used
- Python 3.12
- Pandas
- NumPy
- Matplotlib
- VS Code

## Project Features
- CSV data import
- Data exploration and analysis
- Missing value identification and handling
- Duplicate record removal
- NumPy statistical calculations
- Region-wise sales analysis
- Product-wise sales analysis
- Profit and profit margin analysis
- Business insights
- Bar Chart, Pie Chart and Line Chart visualizations

## Project Structure
- `01_product_bar_chart.py`
- `02_numpy_analysis.py`
- `03_pandas_analysis.py`
- `04_data_cleaning.py`
- `05_sales_visualization.py`
- `06_sales_dashboard.py`
- `07_profit_analysis.py`
- `sales_data.csv`
- `cleaned_sales_data.csv`
- `charts/`

## How to Run
1. Install Python.
2. Install required libraries:
   `python -m pip install pandas numpy matplotlib`
3. Open the project folder in VS Code.
4. Run the required Python file.

## Objective
To develop practical data analytics skills and understand how Python can be used to transform raw sales data into meaningful business insights.
